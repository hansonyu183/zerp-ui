# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | 需要维护者评估 |
| needs-info | needs-info | 等待必要信息 |
| ready-for-agent | ready-for-agent | 规格明确，可由 Agent 实施；远端交付仍须遵守原生阻塞关系 |
| ready-for-human | ready-for-human | 需要人工执行 |
| wontfix | wontfix | 不实施 |

ready-for-agent 不替代前票本地验收，也不是生产部署授权；本地实施与远端交付的阻塞边界见 `docs/agents/issue-tracker.md`。

Skill 提及 canonical triage role 时，使用上表对应的 Label。
