# UI 结构、输入与权限推导

对应[#106](https://github.com/hansonyu183/zerp-ui/issues/106)，design-only。

## 确定性结构选择

先校验协议和Schema，再形成内部能力模型；不能根据一次响应的数据样本猜结构。未知结构保留可达的协议错误，不开放通用JSON表单。

- Page<Record>：桌面有至少3个可展示的顶层标量/引用列时为表格，否则为列表；手机默认卡片。稳定id不计入列数。
- 同类children接口及父子身份：树；至少3个数据列则树表。逐节点加载/分页/失败重试，拒绝循环、重复身份和超过预算的展开。
- Record：详情事实；与当前可写Schema交集形成Form。复杂对象形成领域区块，多区块由库选择Tab，单区块直接展示。
- 对象数组：有稳定id的明细；桌面表格编辑，复杂行/手机使用行Form。关系增加、删除和重排只有对应API业务能力存在时才出现。
- 固定查询与结果接口：报表View；版本/发布接口：配置View；状态转换：办理View；作业/逐项结果：处理/批量View。
- 多种能力组合成一个资源页面，不重复生成同资源菜单。默认入口依次为工作台、固定查询、记录集合、当前版本、处理输入、单条事实。

库继续持有Vuetify组件、MD1/2/3明暗主题、固定顶栏、反馈和弹层，API不能覆盖布局。

## 输入选择及优先级

1. writeOnly/password采用秘密输入，永不回填；readOnly或不在当前写入Schema的字段采用只读事实。
2. 明确候选接口优先于普通标量；单一标识为引用，标识数组为多引用，自关联候选为树选择。依赖必填参数尚未满足则禁用候选输入，不清除已保存的历史值。
3. 中文枚举oneOf/enum采用单选下拉；标量枚举数组采用多选。
4. date/Month/DateRange固定数据类型采用相应日期输入；integer采用整数，number只用于允许非精确量（例如打印毫米尺寸），Decimal/Money/Quantity保持字符串。
5. boolean在Form中使用复选框；独立二值偏好由库使用目标状态动作，不能把每次键入变成保存。
6. 普通string若maxLength≤200且不是有界源码内容则单行；其余为多行。源码使用库内文本编辑，不在浏览器执行服务器代码。
7. 同构对象/数组/类型化映射采用嵌套Form、明细或键值编辑；业务条件改变后重新采用服务器有效Schema，不运行Schema条件脚本。
8. 文件依据实际upload/download接口和媒体类型选择上传/预览；binary不是JSON字段。首版不添加时间、颜色、富文本或滑块等当前OIT不需要的专用控件。

缺失、null、空字符串、0、false分别保留；不能用truthy转换。默认值只在新草稿由服务器采用。精度、单位转换、引用资格及跨字段校验由后端负责。

## 权限与状态

| API业务事实 | UI行为 | 服务端要求 |
| --- | --- | --- |
| 无读取资源/字段资格 | 隐藏入口/字段，清理旧内容 | 不返回其数据，Schema/目录不暴露该读取能力 |
| 无某操作执行资格 | 隐藏操作 | 直接调用仍拒绝 |
| 有资格但业务前提不满足 | 禁用操作并显示业务原因 | prepare/commit均重验 |
| 可读但当前写入Schema无该字段或readOnly | 只读，可复制，不加入写入差异 | 拒绝额外字段或修改服务器值 |
| 局部计算/提交等待 | 禁止重复动作，保留当前目标 | 请求幂等且可核对 |
| 未知/待核结果 | 保留原请求锁与恢复入口 | 普通查询不能代替精确核实 |

业务资格用operationId及可用前提表达，不返回hidden/disabled/visible/UI readonly开关。字段readOnly是输入/输出契约，不是授权表达式。授权隐藏和业务暂不可用须使用不同错误/原因码。

覆盖集合、记录、字段、行、子项、关联目标和批量项。行级约束绑定稳定id；列可供其它行读取时，未获权单元格不得夹带原值。候选搜索与resolve同样鉴权，不能用历史标签恢复当前无权目标的可点击关系。

401清理认证上下文；403使相应资源/操作失效并重取权威描述；503不能当作无权限或解锁依据。身份/账套/安全代际变化取消旧请求并隔离迟到响应。未知请求最小恢复证据与敏感界面数据分别保全/清理。

## 单据导航中文归纳

类型码首字母决定稳定分组，完整码决定排序；叶子保留完整业务名称。无权/停用类型在输入集合中过滤，空组省略。不得存在A→采购、F→资金收支等映射表。

仅用中文名称：去掉打印类型码和“单、单据、其它、其他、初始化”等通用词；使用Intl.Segmenter中文词及名称中重复的连续汉字词。反复选择能覆盖至少两条未覆盖名称的词，按覆盖条数、词长、首次出现位置排序；剩余名称采用末个有效中文词（无有效词时保留原名），去重并列。只有一个类型时保留其业务名。不能猜测名称中不存在的上位概念，完整名称用于无障碍，视觉省略不丢弃标题内容。

## 关系与聚合

引用读取名称、写入id；候选与详情关系分别鉴权。一对一横向扩展作为有归属的闭合对象，纵向属性按定义展开闭合properties，不能以attr_id/attr_val通用编辑器替代。主/头/主明细/子明细采用有限嵌套对象和数组，逐层稳定rowKey、扩展命名空间及有效写Schema。展示、行编辑、显式增删、权限与事务的完整矩阵见[关系整合](relationships.md)。
