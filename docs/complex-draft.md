# 复杂资料与草稿协作

正式范围见 [#58](https://github.com/hansonyu183/zerp-ui/issues/58) 与 [#60](https://github.com/hansonyu183/zerp-ui/issues/60)。`examples/capabilities/complex-draft.ts` 是合成消费者，使用公开 `@zerp/ui` 包入口定义资料，通过 `AppPage` 运行。使用 package scripts 中的 `dev:capabilities` 后打开 `/complex`；`check:capabilities` 会把示例复制到独立消费者，以 tgz 安装后执行相同交互。

## 已有契约覆盖

| 内容                       | 示例使用的公共契约                                               |
| -------------------------- | ---------------------------------------------------------------- |
| 嵌套地区/仓库与条件说明    | `domainBlocks.fields`、`Fields`、`parentKey`、`when`             |
| 产品单位式多行与另一组价格 | 两个独立的 `domainBlocks.rows`，各自确认/取消                    |
| 配方表头、多行与逐行配料   | `domainBlocks.voucher`、`VoucherEditorDefinition` 的 children 列 |
| 精确金额、零、false、null  | decimal 字符串、integer、boolean 与可空字段                      |
| 历史仓库名称及采用快照     | `ReferenceValue`，当前目录 resolve 不替换已采用事实              |
| 价格计算及必要业务说明     | `DraftCollaboration`、必填 confirm/input、只读计算事实           |
| 未完成输入与离页保护       | 页面汇总的 `EditProtection` 与 `AppPageHandle.requestLeave`      |

消费者持有 DTO、目录、后端协议、业务规则和最终保存；库持有页面及区块布局、局部草稿、计算结果采用、提交禁用和离页交互。局部 get/set/summary 只做同步映射，无网络和最终写入权限。本片没有新增公共接口、布局扩展、模板、CSS、任意命令或私有测试出口。

## 操作与采用边界

打开页面即显示合成原资料。单位、价格和明细的本地编辑必须确认后才进入页面草稿。取消配料面板也会丢弃该面板内已经确认、但尚未向父行确认的子项。integer 输入 `-`、正在编辑的行/子项、计算 pending/失败、缺少必填业务答案都会保持保存不可用；普通离页通过页面确认处理。

更换地区会清空依赖仓库，搜索使用新地区上下文；旧目录响应不会覆盖新目录。历史采用值的名称、ID 和 snapshot 保持原事实，只有用户明确选择才采用新引用。

协作 Adapter 接收隔离的完整草稿。样例以 BigInt 对非负、完整十进制价格作精确加法，保留小数位，不把十进制转换成 Number；这是示例消费者规则。计算显式返回完整草稿，并把计算 basis、result、confirmation 与 answer 写入 `calculation`。必要答案满足后才允许最终保存；输入变化使旧答案失效，消费者后端仍须重新核对输入、计算依据、答案与权限。

计算失败通过页面的“重试业务计算”恢复。取消编辑、新一代输入及会话变化使旧回调失效。局部协作不拥有业务写入或未知结果解锁权限；本示例保存返回已知成功，耐久恢复另见相应工单。

## 本片修复

公开页面组合测试证实：异步计算采用完整草稿的隔离副本时，即使已提交明细内容没有变化，旧实现仍按数组对象身份关闭配料面板，丢失未确认输入。子项编辑现在按已提交行内容比较，等值副本保留本地草稿及 pending，用户仍须显式确认；真实明细变化、重排或删除继续使旧面板失效。确认时也重新比较原已提交内容，不能把旧子项草稿写入已变化的父行。

## 验证范围

`tests/complex-draft.spec.ts` 从公开包入口挂载 AppPage，源码测试只把包模块映射到当前公开源码入口。测试观察页面、页面保护接口及合成 Adapter 最终输入，覆盖完整值/引用快照、两组行、配料确认取消、未完成输入、目录依赖、必填问答、精确计算、失败重试、隔离及取消/迟到响应；另复用现有编辑器重排失效测试验证修复的反向约束。

`scripts/complex-draft-smoke.mjs` 在同一 capabilities 包验收流程中执行：tgz 独立安装和运行示例均经 AppPage 完成单位精确编辑、价格取消、配料确认、必要问答、保存和重读，核对可见结果。类型拒绝检查保留嵌套 decimal 和完整计算草稿形状约束。

这些是库侧合成证据，不是 OIT 或原 ZERP 接入、真实 API/E2E、生产存储、业务计算正确性认证或生产数据迁移验收。真实公司 DTO、引用目录与业务规则需由消费者接入工单验证。
