## 一次性迁移

公开组件与原请求协议不更名；0.11.0 不增加兼容层或 fallback。更新包后重新核对打印输出：默认描边由隐含 1px 改为 0.2mm，默认行高明确为 1.2，长词可换行且内容裁切到固定框。需要指定纸张旋转、水印、字体和精确线宽时提供新的有限事实。`cjk-sans` 需安装受控字体，缺失会阻止打开打印窗口；不同系统字体和真实打印设备的逐字版面不承诺相同。详见 [打印契约](printing/contract.md)。

生产存储须符合既有原子预留、完整原请求不可变、终态单调、exact-ID 历史与幂等完成契约。示例存储修正了对这些契约的实现，不能把旧示例的宽松写入当作允许覆盖终态。已知记录损坏、读取失败或缺失继续锁定并重试。详见 [耐久恢复](durable-recovery.md)。

复杂字段和领域区块继续通过有限内容定义组合；计算只接收隔离草稿，消费者将采用结果、计算依据与回答显式放入草稿，并在后端最终写入时重验。详见 [复杂草稿](complex-draft.md)。

历史迁移必须先证明完整原始请求与批次归属；转换后每次恢复读取和回执采用仍须核对独立完整权威原件，不能只回显 ID/binding。无法证明时保留旧记录并拒绝转换。样例不生成新的权威完成事实，不重发旧已发项。详见 [批次迁移](batch-migration.md)。

## 验收与发行证据

实际命令从 package.json 的 scripts 读取。切片使用定向 AppPage 行为测试和 capabilities tgz 消费者；最终发行使用 `check:release` 的整包门禁，对同一个 tgz 完成公开类型/出口、九类独立安装/构建/浏览器消费者验证。打印仅做本次所需的位图/PDF/解码检查，不建立全站截图回归工程。

正式 Release 随附 `evidence.json`、`SHA256SUMS`、`distribution-evidence.json`，分别记录确切源码 SHA、原始验证命令/退出码、同一 tgz 哈希及下载工件复验。打印工件另附分开的 installed-tgz/built-example 输出及哈希。以 Release 与对应工单评论的实际证据判断阶段，不以本文件声称尚未完成的远端验收。

所有 Adapter、目录、存储、历史记录和条码均为合成；没有修改真实 ZERP/OIT，没有生产写入或真实 API/E2E。浏览器 PDF/位图是浏览器输出证据，不是纸张、扫描器或打印设备兼容认证。
