# 静态模型呈现边界

工作区 `BusinessModel.work.members` 包含业务栏目、领域或直属集合。栏目与可选折叠分类的成员数组决定侧栏顺序。侧栏列出领域，工作台配置后固定在首位。领域内多个获权集合使用 Material Tabs，单集合直接展示，各集合独立查询、授权和保存。详情、新增和编辑留在所属集合内。

`ObjectNode.members` 按数组顺序组织字段、分组和所属 `RecordsNode`。对象分组依据模型结构呈现，所属明细随父对象保存。

分组、表格/手机卡片、覆盖式编辑、工作台和主题均由库实现。呈现要求见 [UI 规范](../../docs/ui-preferences.md)，当前模型边界见[接口说明](../../docs/interfaces/README.md)。类型示例不证明呈现符合，定向公开入口和独立 tgz 的执行证据须单独记录。
