# 可运行静态模型消费者

`consumer.ts` 在登录前直接定义完整响应式 BusinessModel，通过唯一公开 App 绑定。`families.ts` 提供合成的资料、单据、流程、处理、批次、脚本问题、结构化报表及有限文档输出。业务回调全部为本地合成行为，没有公司数据或真实 API。

普通用户使用登录名 viewer，其他合成登录名作为管理员；不校验真实密码。退出清理业务状态，下一次登录沿用同一根引用。消费者负责 owner 回写有效性，库隔离迟到 UI 反馈。此例用于包验收，不作为认证安全实现。

在仓库根目录按 `package.json` 的 Node 和 pnpm 基线安装依赖。用 `pnpm dev:model` 启动本地示例，`pnpm build:model` 构建示例。发行验证用同一个 tgz 独立安装并在浏览器验证公开行为，步骤见[独立消费者与验证](../../README.md#独立消费者与验证)。

只参加编译的完整静态对象另见[模型类型示例](../model-contract/README.md)。其中声明的回调不可用作运行实现。真实 ZERP/OIT 集成、公司领域规则和正式发行不在本例范围内。

UI 库根据页面与窗口调用消费者声明的 load，合成回调把结果写回同一个模型。集合读取接收分页参数，记录读取接收记录 ID。示例导入库样式并向 `App` 传入模型。Vuetify 由 `App` 初始化。
