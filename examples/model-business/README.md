# 模型驱动查询与业务办理

App.vue 仅绑定 consumer.ts 的单一模型；不声明页面类型或组件模板。运行与安装验证命令见 package.json 中 model-business 对应 scripts。

合成场景覆盖查询、采用参数、分组/权威合计、导出、下钻到精确业务办理，未知原请求重载核实且不重发，正式/候选/历史、附件取消与暂存工件复用，单据明细及子明细确定/取消、流程节点身份，批次冻结/未知阻止/重载/停止未发送项，以及有限打印预览、打印确认与重载不重打。耐久 CAS 使用本地存储模拟，业务操作仍由模型回调提供。

打印在浏览器调用边界 stub，不代表物理打印计数。所有数据均为合成数据；没有真实 oit-go/ZERP API/E2E 或生产证据。

0.41.0 使用归属当前owner的管理员权限快照和显式“查询与办理”导航投影；所有业务节点仍保留在完整模型中，不使用页面或权限注册表。
